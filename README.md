## 🚀 Featured Projects

### 🛒 E-Commerce Purchase Intent Prediction

**Python • Scikit-learn • XGBoost • SHAP**

An end-to-end machine learning system designed to predict whether an e-commerce visitor is likely to make a purchase.

**What I worked on:**

- 🧹 Data cleaning & preprocessing
- 🔎 Exploratory Data Analysis
- ⚙️ Feature engineering
- 🤖 Logistic Regression, Random Forest & XGBoost
- 🎯 Validation-based threshold optimization
- 🔍 SHAP model explainability
- 📊 Business-oriented customer-intent segmentation

**Final XGBoost performance:**

| Metric | Score |
|---|---:|
| Accuracy | 75.91% |
| Precision | 33.75% |
| Recall | 56.02% |
| F1 Score | 42.13% |
| ROC-AUC | 78.08% |
